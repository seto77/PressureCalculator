# 4. 스펙트럼과 피팅

루비 형광 모드와 다이아몬드 라만 모드에서 측정 스펙트럼을 불러오고, 평활화하고, 피팅하는 방법을 설명합니다.

## 스펙트럼 불러오기

- **파일 → 불러오기** : 스펙트럼 파일을 엽니다.
- **드래그 앤 드롭** : 스펙트럼 파일을 메인 창에 끌어다 놓습니다.

PressureCalculator는 쉼표, 공백, 탭으로 구분된 숫자 열로 이루어진 일반 텍스트 파일을 읽습니다(구분 문자는 자동으로 감지됩니다). 첫 번째 숫자 열을 가로축(파장 nm 또는 파수 cm⁻¹)으로, 그다음 열을 강도로 사용합니다. 파일 확장자는 무엇이든 상관없습니다.

## 데이터 파일 감시

**파일 → 파일이 갱신되면 다시 불러오기**를 체크하면 PressureCalculator가 불러온 파일을 감시하여 파일이 변경될 때마다 자동으로 다시 불러옵니다. 분광기 소프트웨어가 새 데이터를 저장할 때마다 스펙트럼, 피팅, 압력 값이 갱신되므로 측정 중에 편리합니다.

## 평활화

피팅 전에 서로 독립적인 두 가지 필터로 스펙트럼을 평활화할 수 있습니다.

- **이동 평균** : 이동 평균 창의 너비(데이터 점 수).
- **가우시안 블러 σ** : 가우스 평활화 폭.

다이아몬드 라만 모드에서는 원본 스펙트럼(위쪽 그래프)과 1차 미분(아래쪽 그래프)의 평활화 설정이 서로 독립적입니다.

## 피팅

- **피팅 범위** : 피크(루비 R1/R2) 또는 미분 극소(다이아몬드 라만 에지) 주변에서 피팅에 사용하는 영역의 너비. 단위는 축 단위(nm 또는 cm⁻¹)입니다.
- 피팅된 피크 위치, 폭 (FWHM), 배경 파라미터가 **피팅 정보** 상자에 표시됩니다.
- **소수점 자릿수**로 표시되는 소수 자릿수를 조절합니다.

## 그래프

마우스 왼쪽 버튼으로 사각형을 드래그하면 해당 영역으로 확대됩니다. 아주 작은 드래그(단순 클릭)는 단계적으로 축소합니다. 더블 클릭하면 표시 중인 프로파일 데이터가 텍스트로 클립보드에 복사됩니다. 각 그래프 위의 X/Y 표시는 포인터 위치를 나타냅니다.

## 내보내기

**파일 → CSV로 내보내기**는 표시 중인 스펙트럼(원본, 평활화, 피팅 곡선)을 CSV 파일로 저장합니다.
