# 4. 光譜與擬合

本頁說明如何在紅寶石螢光與鑽石拉曼模式中載入、平滑化並擬合測得的光譜。

## 載入光譜

- **檔案 → 載入** : 開啟光譜檔案。
- **拖放** : 將光譜檔案拖放到主視窗。

PressureCalculator 可讀取由逗號、空格或定位字元（Tab）分隔的數值欄所組成的純文字檔（分隔符號會自動偵測）。第一個數值欄作為橫軸（波長 nm 或波數 cm⁻¹），其後一欄作為強度。副檔名不拘。

## 監看資料檔案

勾選 **檔案 → 檔案更新時重新載入** 後，PressureCalculator 會監看已載入的檔案，並在檔案變更時自動重新載入。這在測量過程中十分方便：每當光譜儀軟體儲存新資料時，光譜、擬合結果與壓力讀值都會隨之更新。

## 平滑化

擬合前可用兩種獨立的濾波器對光譜進行平滑化：

- **移動平均** : 移動平均的視窗寬度（以資料點數為單位）。
- **高斯模糊 σ** : 高斯平滑化的寬度。

在鑽石拉曼模式中，原始光譜（上圖）與其一階微分（下圖）的平滑化設定各自獨立。

## 擬合

- **擬合範圍** : 峰（紅寶石 R1/R2）或微分極小值（鑽石拉曼邊緣）周圍用於擬合的區域寬度，單位為軸的單位（nm 或 cm⁻¹）。
- 擬合所得的峰位置、寬度 (FWHM) 與背景參數顯示於 **擬合資訊** 欄。
- **小數位數** : 變更顯示的小數位數。

## 圖表操作

以滑鼠左鍵拖曳出矩形可放大該區域；輕點一下（極小幅度的拖曳）則逐步縮小。按兩下可將顯示中的曲線資料以文字形式複製到剪貼簿。各圖表上方的 X/Y 讀值顯示游標位置。

## 匯出

**檔案 → 匯出為 CSV** 可將顯示中的光譜（原始資料、平滑化與擬合曲線）儲存為 CSV 檔案。
