# 4. 光谱与拟合

本页说明在红宝石荧光模式和金刚石拉曼模式下，如何加载、平滑和拟合测量光谱。

## 加载光谱

- **文件 → 加载** : 打开光谱文件。
- **拖放** : 将光谱文件拖放到主窗口上。

PressureCalculator 读取由逗号、空格或制表符分隔的数值列组成的纯文本文件（分隔符自动识别）。第一个数值列作为横轴（波长 nm 或波数 cm⁻¹），其后一列作为强度。文件扩展名不限。

## 监视数据文件

勾选 **文件 → 文件更新时重新加载** 后，PressureCalculator 会监视已加载的文件，并在文件发生变化时自动重新加载。这在测量过程中非常方便：光谱仪软件每保存一次新数据，光谱、拟合结果和压力读数都会随之刷新。

## 平滑

拟合前可用两个相互独立的滤波器对光谱进行平滑：

- **移动平均** : 滑动平均的窗口宽度（以数据点数计）。
- **高斯模糊 σ** : 高斯平滑的宽度。

在金刚石拉曼模式下，原始光谱（上方图形）与其一阶微分（下方图形）拥有各自独立的平滑设置。

## 拟合

- **拟合范围** : 峰（红宝石 R1/R2）或微分极小值（金刚石拉曼边）周围用于拟合的区域宽度，以横轴单位（nm 或 cm⁻¹）表示。
- 拟合得到的峰位、峰宽（半高全宽 FWHM）和背景参数显示在 **拟合信息** 框中。
- **小数位数** 控制显示的小数位数。

## 图形操作

按住鼠标左键拖出矩形可放大该区域；单击（极小幅度的拖动）则逐级缩小。双击可将当前显示的谱线数据以文本形式复制到剪贴板。各图形上方的 X/Y 读数显示指针位置。

## 导出

**文件 → 导出为 CSV** 可将当前显示的光谱（原始数据、平滑后数据和拟合曲线）保存为 CSV 文件。
