# 1. ルビー蛍光

ダイヤモンドアンビルセル実験で最も広く使われる圧力ゲージである、ルビー R1 蛍光線のシフトから圧力を決定します。メインウィンドウ上部の **ルビー蛍光** を選択してください。

![ルビー蛍光モード](../assets/cap-ja-auto/FormMain-ruby.png){width=700px}

## 操作の流れ

1. 蛍光スペクトルを読み込むか（[スペクトルとフィッティング](4-spectra-and-fitting.md)参照）、**R1** ボックスに R1 波長 (nm) を直接入力します。
2. スペクトルを読み込むと、**フィッティング範囲** 内で R1・R2 線をフィッティングし（pseudo-Voigt プロファイル + 直線バックグラウンド）、ピーク位置と幅を **フィッティング情報** 欄に表示します。
3. **参照条件** グループで基準条件（ゼロ圧力での R1 波長 **R1₀**）を設定します。**現在の R1 を設定** を押すと、現在フィットされている R1 が参照ボックスにコピーされます。
4. 各ルビースケールで計算された圧力が **圧力計算** グループに表示されます (GPa)。

## ルビースケール

圧力は次式で計算されます。

$$P = \frac{A}{y}\left[\left(\frac{R1}{R1_0}\right)^{y} - 1\right]$$

パラメータは以下のスケールから選べます（係数は編集可能です）。

| スケール | 備考 |
|---|---|
| Mao (1978) | A = 1904 GPa, y = 5 |
| Mao-quasi (1986) | 準静水圧条件, y = 7.665 |
| Mao-hydro (2000) | 静水圧条件, y = 7.715 |
| Shen et al. (2020) | 国際実用ルビースケール, P = 1870 × Δ(1 + 5.63 Δ), Δ = (R1 − R1₀)/R1₀ |

## 温度補正

R1 線は温度によってもシフトします。**温度依存性 (Ragan et al., 1992)** グループでは、測定温度と参照温度を用いてこの効果を補正します。適用範囲は 50-600 K です。

- **温度単位** : ケルビンまたは摂氏。
- **参照条件と同じ** : 測定温度を参照温度と同じとみなします。
- **Ragan の式から計算** : R1₀ を手入力する代わりに、指定温度における値を Ragan の式から計算します。
